# Coupled Von Bertalanffy–Angiogenesis Model

This repository contains the Python implementation used for the
numerical analysis of a coupled Von Bertalanffy–angiogenesis model
for glioblastoma tumor growth.

## Numerical method

The model is solved using the classical fourth-order
Runge–Kutta (RK4) method.

Time step:
Δt = 0.01 day

## Requirements

Python 3.x
NumPy
SciPy
Matplotlib
Pandas

## Reproducibility

The scripts reproduce the numerical simulations,
convergence analysis, and figures reported in the manuscript.
